# Nawafth-ALbnaa

تطبيق شركة نوافذ البناء - إدارة المخازن، المطبخ، المشتريات، التقارير اليومية، المهام والإشعارات.

## المميزات

- **المخازن**: إضافة مادة / سحب مادة مع تاريخ العملية وجدول حركات ورصيد تلقائي
  (الحاويات، القاعة، مخزن بناية 6).
- **المطبخ**: نفس نظام الجرد (إضافة/سحب + جدول مع التواريخ).
- **الإشعارات**: إشعارات فورية داخل التطبيق بين جميع الأجهزة +
  إمكانية إرسال إشعارات Push للموبايل عبر Firebase Cloud Messaging.
- **التقرير اليومي**: تصميم احترافي مع ملخص إحصائيات (إجمالي التقارير / تقارير اليوم).
- **المهام**: لكل مهندس عدد المهام المضافة وعدد المهام المنجزة.

## تفعيل إشعارات Push للموبايل (خطوة إلزامية واحدة)

1. افتح **Firebase Console** > مشروع `nawafth-albnaa` > **Project Settings** > **Cloud Messaging**.
2. أنشئ شهادة Web Push Certificates وانسخ **Key Pair**.
3. افتح `script.js` وضع المفتاح في الثابت:
   ```js
   const VAPID_KEY = "ضع_المفتاح_هنا";
   ```
4. ارفع ملفات المشروع إلى **Firebase Hosting** (أو أي استضافة HTTPS).

## خطوات اختيارية: إرسال الإشعارات حتى عندما تكون فتحة التطبيق مقفلة

بشكل افتراضي تعمل الإشعارات لحظياً بين الأجهزة المفتوحة للتطبيق.
لإرسالها لأجهزة الموبايل حتى أثناء إغلاق التطبيق:

1. `cd functions`
2. `npm install`
3. ثم من جذر المشروع: `firebase init functions` (اختر المشروع `nawafth-albnaa`)
4. `firebase deploy --only functions`

> ملاحظة: يجب أن تسمح قواعد Firestore بالقراءة والكتابة لمجموعات
> `notifications` و `notificationTokens` و `materials`.

## التطبيق محلياً

افتح `index.html` على أي خادم HTTP (أو استخدم `npx serve`) — الإشعارات تتطلب HTTPS، لكن `localhost` تعمل أيضاً.
